How the value is worked out

implied value = TVL × peer multiple × maturity. The peer multiple is the median market-cap-to-TVL ratio of live-token protocols in the same category, fitted from this snapshot at run time (a category with fewer than 3 live peers falls back to the global median). Maturity is 0.6 for a newborn protocol and rises to 1.0 after three years without a token. No protocol name is ever special-cased.

Each row also shows an honest range, from the 25th to the 75th percentile of the same category's ratios, so one number never pretends to be certain. Two terms were measured and left out of the value: launch odds by age and seven-day growth both made the blind tests worse, so growth is shown as a column and a stability marker only, and the odds appear as a launch-readiness column and in the farm verdict, never in the value.
